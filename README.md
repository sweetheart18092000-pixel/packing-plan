# 📦 WhatsApp Packing Plan Report Generator

Modern, responsive web app to generate formatted WhatsApp packing reports from `Dump.xlsx`.

## ✨ Features
- Instant zero-latency search by Job Number (2,116+ pre-indexed jobs).
- Auto-fill for PO #, Style #, Finish Name, Quantity, and Buyer.
- 1-click formatted copy for WhatsApp groups.
- Direct WhatsApp sharing.
- Works 24/7 on Mobile, Desktop, and Tablets.
